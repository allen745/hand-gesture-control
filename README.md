**Overview**
This project uses the Three.js library to create a 3D particle morphing simulation that interacts with hand tracking using MediaPipe Hands. The simulation features various shapes, including DNA, torus knots, cubes, galaxies, and pyramids, which can be changed by pinching the thumb and index finger together. The system can also detect the openness of the palm to adjust the chaos level of the particles.

**Usage**

Open the HTML file in a web browser to start the simulation.
Allow the browser to access the camera and microphone.
Hold up your hand with the palm facing the camera to start the hand tracking.
Pinch the thumb and index finger together to change the shape of the particles.
Open or close your palm to adjust the chaos level of the particles.
**Features**

Hand tracking: The system uses MediaPipe Hands to track the position and orientation of the hand.
Shape changing: The shape of the particles can be changed by pinching the thumb and index finger together.
Chaos level adjustment: The chaos level of the particles can be adjusted by opening or closing the palm.
Various shapes: The system features multiple shapes, including DNA, torus knots, cubes, galaxies, and pyramids.
Interactive simulation: The simulation is interactive and responds to hand movements and gestures.
Installation
To run this project, simply open the HTML file in a web browser. Make sure the browser has access to the camera and microphone. You can also clone this repository or download the code and run it locally.

**Compatibility**
This project is compatible with modern web browsers that support WebGL and Web Workers.

**Troubleshooting**
If you encounter any issues with the project, you can try the following:

Check browser compatibility: Make sure your browser is compatible with the project.
Grant camera and microphone access: Ensure that the browser has access to the camera and microphone.
Check for conflicts with other scripts: If you're running other scripts or plugins that use the camera or microphone, try disabling them to see if it resolves the issue.
